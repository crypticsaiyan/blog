# blog

my personal blog, at [blog.crypticsaiyan.me](https://blog.crypticsaiyan.me).

this is a modified version of [snippet-book](https://github.com/jitinnair1/snippet-book), itself based on [jekyll-theme-console](https://github.com/b2a3e8/jekyll-theme-console). styling has been reworked to match my [portfolio](https://crypticsaiyan.me) and terminal setup (nvim + kitty, catppuccin mocha).

## development

```
bundle install
bundle exec jekyll serve
```
