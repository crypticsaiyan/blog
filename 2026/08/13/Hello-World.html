Who am I?

Well… that’s a deep philosophical question.

Some Background

I’m pretty sure that my programming journey didn’t start with printing “Hello World” in the terminal. I had an interest in programming since my childhood and I can remember building frontend websites and watching Python tutorials in 8th grade. But I left programming (and pretty much everything) and began preparing for competitive exams. And after studying some Physics, Maths and Chemistry, I took admission in CSE branch at IIT Dhanbad :P.

You can think of me as a curious guy who likes to dive into interesting things.

Daily Driver

I use Arch btw

My roommate introduced me to Linux two years ago and I’ve been using it since then. At first I installed Ubuntu but it didn’t suit me so I switched to Manjaro KDE Plasma. It wasn’t the best for my laptop (speakers, camera, bluetooth often broke after updates) but I liked using it. Particularly, I got used to using the AUR. Then I tried installing vanilla Arch several times on my laptop both in the manual way and using the archinstall script, but wasn’t able to make it work (skill issue ig ;( ). So I gave Garuda Linux a try and I haven’t looked back since. I had also developed a habit of “ricing” (making things look cooler) my OS which cost me a lot of time doing meaningless changes in the ~/.config folder. You can check out my dotfiles on github.

As a result, you’ll find me using the terminal more than anything else.

Future?
